# VP Workbench

基于 Tauri 的桌面视频处理工作台，当前围绕“配置先行”的单一工作流构建：

1. `home`：启动探测、能力缓存与运行时概览
2. `input`：批量导入素材
3. `decode`：解码方案与硬件设备
4. `enhance`：补帧 / 超分 / 动漫优化
5. `encode`：编码器与输出配置
6. `render`：批处理队列与任务日志

## 仓库结构

- `backend/`：Python CLI 与流式处理链路
- `frontend/`：Vue 3 + TypeScript + Pinia + Vue Router
- `frontend/src-tauri/`：Tauri v2 桌面外壳、权限与运行时桥接

## 当前桌面命令面

桌面端只保留下面这些 Tauri commands，并与权限清单一一对应：

- `pick_inputs`
- `pick_output_directory`
- `check_environment`
- `load_workbench_preset`
- `save_workbench_preset`
- `inspect_video`
- `start_task`
- `cancel_task`
- `open_output_location`

后端 CLI 只保留下面三个入口：

- `python -m app check`
- `python -m app info --input <video>`
- `python -m app process --input <video> ...`

## 本地开发

### 后端测试

```powershell
python -m pytest backend\tests -q
```

### 前端依赖安装

```powershell
cd frontend
npm install
```

### 前端测试

```powershell
cd frontend
npm run test
```

### 前端构建

```powershell
cd frontend
npm run build
```

### Tauri 桌面开发

```powershell
cd frontend
npm run tauri:dev
```

### Tauri Rust 测试

```powershell
cd frontend\src-tauri
cargo test --quiet
```

## 生成物与忽略规则

- 根 `.gitignore` 只处理仓库级缓存、样例媒体和工作区产物。
- `backend/.gitignore` 负责 Python 缓存、运行日志、输出目录和本地模型权重。
- `frontend/.gitignore` 负责 `node_modules`、`dist`、`src-tauri/target` 以及 Tauri 自动生成权限文件。
- `frontend/src-tauri/permissions/autogenerated/` 是构建时生成目录，默认忽略，不手工维护。
- `frontend/src-tauri/gen/schemas/*.json` 是当前仍受 Git 跟踪的生成文件，修改命令面或权限后需要一并同步。

## 运行时资源解析

桌面外壳会按以下顺序解析运行时资源：

1. 显式环境变量覆盖，例如 `VP_FFMPEG_PATH`、`VP_FFPROBE_PATH`、`VP_RIFE_MODEL_DIR`、`VP_RUNTIME_ROOT`
2. `frontend/src-tauri/resources/` 内打包资源
3. 开发环境下的工作区源码布局
4. 系统级 Python / FFmpeg 兜底
